HAVENIA FOODS — STATIC WEBSITE
================================

Files:
- index.html — complete responsive website, including CSS and a tiny JS year updater.
- photos/hero.png — current generated hero artwork.
- photos/products/ — drop replacement product photos here using the filenames listed below.

PHOTO PLACEHOLDERS
------------------
The site intentionally has no stock/product photography yet.
Replace any element with class "photo-placeholder" with an image, for example:

<img class="hero-photo" src="images/founder.jpg" alt="..." />

For product cards, keep the existing .product-photo sizing or add your own image styling.

BEFORE PUBLISHING
-----------------
1. Replace hello@haveniafood.co.in with the real business email.
2. Add the actual domain in your hosting/DNS setup.
3. Add real product photos.
4. Add the final 8th product when its name/photo are ready.
5. Add Instagram / WhatsApp / retailer links if desired.
6. Review product claims and descriptions against the final packaging.

DESIGN DIRECTION
----------------
Warm cream + deep wine + saffron + muted green.
The structure deliberately treats HAVENIA FOODS as the parent company and
VYANJANS as the first brand, so additional brands can be added later without
redesigning the whole site.
